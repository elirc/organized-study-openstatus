# 07 — Career & Collaboration

Code gets merged by humans. This module covers the three written genres that decide whether your work lands:

1. [01-code-review-mindset.md](01-code-review-mindset.md) — the five review layers + a repo-specific checklist + comment language.
2. [02-writing-prs-and-rfcs.md](02-writing-prs-and-rfcs.md) — PR descriptions, commit messages, when and how to RFC.
3. [03-maintainer-communication.md](03-maintainer-communication.md) — asking, reporting, disagreeing; templates.

These skills are directly interviewed ("walk me through a PR you're proud of", "tell me about a review disagreement") — every artifact you produce here is also STAR-story raw material for [08/06](../08-interview-prep/06-behavioral-star-stories.md).
