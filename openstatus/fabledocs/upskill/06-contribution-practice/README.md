# 06 — Contribution Practice

Learning ends in shipped diffs. This module is a ladder of increasingly real work:

1. [01-good-first-tickets.md](01-good-first-tickets.md) — 16 junior tickets (tests, small fixes, one-file changes).
2. [02-mid-level-feature-tickets.md](02-mid-level-feature-tickets.md) — 10 cross-layer tickets requiring design notes, risk, and rollback sections.
3. [03-senior-build-projects.md](03-senior-build-projects.md) — 6 projects (days–weeks) with full design checklists.
4. [04-refactor-and-design-katas.md](04-refactor-and-design-katas.md) — 8 judgment katas with self-grading criteria.

Every ticket/project carries an **Interview story potential** line — completing it mints a STAR story for [08/06](../08-interview-prep/06-behavioral-star-stories.md).

Contribution realism (non-negotiable, from the root README): before writing code, answer — why is it useful, why is the blast radius small, what existing pattern does it follow, how is it tested, what would make a maintainer reject it. Anchors were verified 2026-07-11; **always re-open them before starting** — this is a living codebase.
