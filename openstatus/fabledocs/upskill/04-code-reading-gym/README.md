# 04 — Code Reading Gym

Active practice. Reading code passively teaches almost nothing; these four workouts force prediction, annotation, and judgment — the three muscles interviews and code review actually test.

1. [01-annotation-drills.md](01-annotation-drills.md) — 10 real excerpts; annotate inputs/outputs/invariants/side effects/failure modes.
2. [02-trace-tables.md](02-trace-tables.md) — 5 step-by-step traces with value shapes and risk columns.
3. [03-fake-code-contrasts.md](03-fake-code-contrasts.md) — 10 bad-vs-better pairs (all fake, all labeled) tied to real repo patterns.
4. [04-review-katas.md](04-review-katas.md) — 8 fake PRs to review with blocking/important/optional findings.

Rules: write your answers down before reading answer keys; grade yourself with the rubrics; when you miss a Strong-level item, chase the anchor until you could re-derive it. One drill/day beats ten in a binge.
