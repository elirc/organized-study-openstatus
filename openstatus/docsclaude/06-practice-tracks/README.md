# 06 — Practice Tracks

Reading without doing produces a *librarian*, not an engineer. This module is the doing part. Four tracks, each progressively more demanding:

| # | Track | Purpose |
| --- | --- | --- |
| 01 | [`01-reading-katas.md`](01-reading-katas.md) | Short, dense reading exercises with rubrics. Builds the reading reflex. |
| 02 | [`02-modify-tickets.md`](02-modify-tickets.md) | 10 small but real tickets. Each touches a different layer. |
| 03 | [`03-build-projects.md`](03-build-projects.md) | 5 progressively deeper builds. Each is an integration of the prior modules. |
| 04 | [`04-senior-katas.md`](04-senior-katas.md) | Design and refactor exercises — no clear "right answer." |

## How to use

Pick one track at a time. Don't bounce. Track 1 should take a few hours total; tracks 2-4 are weeks of work if done seriously.

Resist the temptation to ask an AI for the answer. Use AI as a question-asker (the prompt template at the bottom of each track). The point is to build your own reflexes.
