# Pattern Recognition Handbook

This suite is for learners who understand code faster once they can name recurring patterns. It teaches OpenStatus as a set of recognizable engineering moves: boundary adapters, runtime schemas, service transactions, derived public read models, side-effect ownership, and test isolation.

Pattern recognition turns "I am lost in files" into "I have seen this shape before." Each pattern includes:

- where it appears in real code,
- why the pattern exists,
- fake code that isolates the idea,
- review questions to ask when you see it again.

Primary anchors include `packages/api/src/router/statusReport.ts:21-222`, `packages/api/src/service-adapter.ts:18-87`, `packages/services/src/status-report/create.ts:24-99`, `packages/services/src/status-report/list.ts:66-226`, and `packages/api/src/router/statusPage.ts:65-400`.
